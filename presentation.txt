Title: Security Drift Intelligence
Subtitle: Problem, Solution, and SOC Dashboard Implementation

slide2
Problem Statement
- Cloud control drift is hard to detect across AWS/Azure sources.
- Security teams need a SOC-ready operational view with risk scoring, anomaly detection, and incident triage.
- Existing dashboards were too generic and lacked analyst-focused security context.

slide3
Solution Overview
- Built a hybrid drift intelligence platform combining rules, ML, and anomaly detection.
- Created a SOC-style Streamlit dashboard for triage, attack simulation, and incident submission.
- Generated executive reports and compliance artifacts automatically.

slide4
System Architecture
- Ingestion: AWS CloudTrail, Azure audit, CSV drift exports.
- Normalization: unified event contract and feature enrichment.
- Analysis: rule engine, ML risk engine, behavioral anomaly engine.
- Prioritization: weighted risk score with deterministic critical floors.
- UI: SOC dashboard plus reporting output.

slide5
Deterministic Rules
- Implemented enterprise rule engine with explicit security rules.
- Rules detect CloudTrail disablement, MFA removal, encryption downgrade, audit logging gaps, public exposure, and more.
- Each rule produces a risk score, compliance mapping, remediation guidance, and evidence narrative.

slide6
Machine Learning Risk Engine
- Trained a Random Forest classifier on derived weak labels.
- Uses categorical and numeric security features.
- Produces probability-weighted ML risk scores and confidence metrics.
- Supports model persistence with schema and version metadata.

slide7
Behavioral Anomaly Detection
- Used Isolation Forest to identify unusual changes independent of severity.
- Focused on behavior patterns like time, control type, and change reason.
- Outputs anomaly score, flag, and confidence.
- Provides an orthogonal signal to rule-based severity.

slide8
Threat Prioritization
- Combined security rule score, ML risk score, and anomaly confidence.
- Weighted formula: 50% rules, 35% ML, 15% anomaly.
- Applied mandatory critical floors for top-risk rule detections.
- Final output: priority score, priority level, and justification.

slide9
Dashboard Design
- Redesigned UI as SOC Command Center with dark enterprise theme.
- Added tabs for Executive Summary, Security Drift, Compliance, LLM Analyst, Attack Simulation, and Model Assurance.
- Included analyst-focused controls, alert evidence, and contextual metrics.
- Added incident submission flow to persist SOC tickets.

slide10
Attack Simulation
- Created attack simulation feature from top-scoring alerts.
- Maps drift evidence into adversary-style patterns like Data Exposure, Visibility Evasion, and Privilege Escalation.
- Provides scenario descriptions and remediation command templates.
- Helps analysts understand likely attacker intent.

slide11
Validation and Reporting
- Generates executive audit report in markdown and PDF.
- Produces remediation playbooks and compliance violation CSVs.
- Includes model assurance metrics: cross-validation F1, feature importance, and scenario validation accuracy.
- Enables both SOC and audit-ready delivery.

slide12
Outcome and Value
- Delivered a complete security drift intelligence platform.
- Turned raw cloud drift data into SOC-ready alerts and incident workflow.
- Improved analyst visibility with explainable risk scoring and attack simulation.
- Created a practical dashboard plus documentation for continued use and expansion.
